# Pituach — Site estático

Este repositório contém os arquivos do site estático da Pituach, pronto para upload na Hostinger.

Conteúdo:
- index.html (Home)
- about.html, services.html, portfolio.html, blog.html, contact.html
- templates/ (6 páginas demo)
- assets/ (css, js, logo svg e ícones)
- assets/form/contact.php (handler PHP para Hostinger)

Instruções de deploy:
1. Baixe o ZIP (Code → Download ZIP) ou clone o repositório.
2. Faça upload do conteúdo para a pasta public_html (ou www) na Hostinger via painel ou FTP.
3. Verifique permissões e compatibilidade PHP (mail()).
4. Para melhorar a entrega de emails, configure SMTP e use PHPMailer (opcional).

Substitua o logo em assets/logo.svg e o favicon em assets/favicon.png conforme necessário.

Se precisar, posso gerar uma versão com imagens otimizadas em WebP e incluir PHPMailer configurado.
